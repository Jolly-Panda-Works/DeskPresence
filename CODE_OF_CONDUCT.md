# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and welcoming, assume good intent, and keep discussions about the work.
Harassment, insults and personal attacks are not tolerated.

Report unacceptable behaviour privately to the maintainer, [Usef Farahmand](https://github.com/Usef-Farahmand).
